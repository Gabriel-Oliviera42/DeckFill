# Produto

## Visão

DeckFill deve virar uma ferramenta de preparação de proxies para TCGs: o usuário cola uma decklist, escolhe artes quando necessário, ajusta o modo de impressão e gera um PDF pronto para imprimir em casa ou enviar para um parceiro profissional.

A ideia não é ser apenas "um MTG Print alternativo", mas uma camada mais completa para quem trabalha com proxies: organizar listas, reduzir retrabalho, padronizar arquivos e criar um fluxo comercial mais direto entre cliente e impressor.

## Hipótese Atual

Depois da primeira conversa sobre o possível parceiro, a hipótese mais forte é:

DeckFill deve começar como um lugar onde pessoas montam pedidos de proxy, revisam visualmente as cartas e enviam uma solicitação organizada para quem imprime.

Nesse modelo, o cliente não precisa necessariamente baixar ou gerar o PDF final. O PDF pode virar uma função interna, protegida ou administrativa, usada pelo parceiro depois que o pedido estiver revisado.

Isso muda a pergunta central do produto:

- Antes: "Como eu gero um PDF perfeito?"
- Agora: "Como eu transformo uma lista bagunçada em um pedido claro, revisado e fácil de produzir?"

## Público-Alvo

### Jogadores

Pessoas que querem imprimir proxies para teste, Commander casual, cube, playtest ou uso privado.

Necessidades:

- Colar decklist rapidamente.
- Escolher versões bonitas das cartas.
- Gerar PDF sem entender de layout.
- Imprimir frente e verso quando necessário.
- Evitar gastar tempo ajustando tamanho, corte e margens.

### Profissionais de proxy

Pessoas que recebem listas de clientes e precisam transformar pedidos em arquivos imprimíveis.

Necessidades:

- Reduzir conversa manual com cliente.
- Receber decklists mais padronizadas.
- Gerar PDFs previsíveis para corte.
- Ter presets de impressão próprios.
- Futuramente salvar clientes, pedidos, status e histórico.

## Valor Atual

O DeckFill já entrega valor real em quatro pontos:

- Parse de decklists e busca automática de cartas.
- Grade visual para revisar as cartas encontradas.
- Escolha de artes/reimpressões para Magic.
- Geração de PDF com opções de sangria, guias, tamanho e verso.

## Diferenciais Possíveis

- Fluxo pensado para parceiro de impressão, não só para usuário final.
- Presets por tipo de impressora/cortadora.
- Suporte multi-TCG.
- Upload de artes customizadas.
- Pedido pronto para WhatsApp ou painel do profissional.
- Padronização de arquivos para corte profissional.
- Histórico de pedidos e reimpressão.

## Relação com Ferramentas de Produção

O parceiro citou `silhouette-card-maker` como solução que já atende bem a etapa de produção/corte. Portanto, o DeckFill não deve tentar competir imediatamente com essa parte.

O caminho mais inteligente é complementar:

- DeckFill: entrada do pedido, busca, revisão visual, seleção de cartas, organização e envio.
- Ferramenta de corte/PDF: produção final, templates, offset, calibração e corte.

Depois, se fizer sentido, o DeckFill pode gerar arquivos compatíveis com o fluxo de produção do parceiro.

## Cuidados Comerciais

Antes de vender ou apresentar como produto comercial, vale separar bem:

- O DeckFill como ferramenta de preparação de arquivos.
- O parceiro como responsável pelo serviço de impressão.
- O uso de imagens, marcas e proxies como tema que precisa de validação legal e operacional.

O pitch deve evitar prometer autorização oficial de Magic, Pokémon, Yu-Gi-Oh! ou qualquer outra marca.

## Pitch Curto

DeckFill é uma ferramenta que transforma decklists em PDFs de proxy prontos para impressão. Ela automatiza busca de cartas, seleção de artes, layout, sangria, verso e preparação para corte, reduzindo o trabalho manual de quem imprime proxies para clientes.

Versão mais alinhada à hipótese atual:

DeckFill é um portal de pedidos para proxies de TCG: o cliente cola a lista, revisa as cartas, escolhe opções e envia um pedido organizado para o profissional produzir sem ficar decifrando mensagens soltas.

## Pitch Para Parceiro de Proxy

Hoje, boa parte do trabalho de proxy acontece na conversa: cliente manda lista, a pessoa confere carta por carta, ajusta arte, monta folha, resolve corte e ainda precisa corrigir erros. O DeckFill pode virar a etapa anterior do pedido: o cliente monta o PDF de forma padronizada, ou o profissional usa a ferramenta para preparar pedidos mais rápido, com presets próprios e menos retrabalho.
